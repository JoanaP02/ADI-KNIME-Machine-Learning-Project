# KNIME Machine Learning Project

Academic machine learning project developed using **KNIME** at the **University of Minho**.

The project used two datasets:
- Airbnb listings in New York City
- Obesity-related health data

## Main Topics

- Data preprocessing
- Exploratory data analysis
- Classification
- Regression
- Neural Networks
- K-Means Clustering
- Model evaluation

## Tools

- KNIME
- Machine Learning
- Data Mining

## Files

- `ADI_tarefa_A.knwf` — Airbnb workflow
- `trabalho_tarefa_B.knwf` — Obesity workflow
- `AB_NYC_2019.csv` — Airbnb dataset
- `RelatorioADI_G6.pdf` — Project report
